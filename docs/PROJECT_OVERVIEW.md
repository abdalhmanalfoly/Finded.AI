# FindIt AI — Project Overview

FindIt AI is a lost-and-found platform concept. Users can publish lost/found reports, attach images, browse public reports, receive suggested matches, request contact, and exchange messages after acceptance. Administrative tools support report and user moderation.

The supplied codebase is a React/Vite frontend backed by Supabase SQL migrations and a deterministic PostgreSQL matching engine. Preview Mode uses sample data when Supabase public environment variables are absent.

This is not yet a verified production deployment. See `PROJECT_AUDIT.md` and `PRODUCTION_CHECKLIST.md`.
