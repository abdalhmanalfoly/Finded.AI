# FindIt AI — User Guide

## Browse
Use Lost Items or Found Items to browse public reports. Search supports text such as item name, description, location, city, and brand. Category, color, and date range filters narrow the results.

## Report
Sign in, choose Report Lost or Report Found, complete the item details, and attach supported images (JPG, PNG, or WebP; current client limit 5 MB per image).

## Matches and contact
Review suggested matches and their explanations. Contact requests are used to initiate a conversation; private contact information should not be shared in public report descriptions.

## Account and safety
Keep serial numbers, passwords, government ID details, and private contact information out of public descriptions. Meet in a safe public location and verify ownership before handing over an item.

Some actions are unavailable in Preview Mode until Supabase is configured.
